# 럭스테라피 (LuxeTherapy)

출장마사지·홈타이 방문 안내 정적 사이트. 외부 의존성 없이 Node 20 표준 라이브러리만 쓴다.

## 돌리는 법

```bash
npm run regions   # 행정동 경계 → data/regions.json (원본 geojson 필요)
npm run build     # dist/ 생성
npm run check     # 빌드 결과 자체 검사
npm run simil     # 동 안내문끼리 본문 겹침 측정
npm run serve     # dist/ 를 로컬에서 띄워 보기
```

## 호스팅 — Cloudflare Workers (정적 자산)

저장소를 Cloudflare Workers Builds 에 연결한다. 정적 자산만 올리는 워커라 `main` 이 없고 설정은 `wrangler.jsonc` 에 있다.

| 칸 | 값 |
|---|---|
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` (기본값 그대로) |
| 환경 변수 | `NODE_VERSION` = `20` |

기준 주소는 `data/site.config.json` 의 `siteUrl` 한 곳이다. 소스에는 주소를 적지 않는다. 배포 주소가 정해지면 이 값만 바꾸고 다시 빌드한다.
`_headers` 와 `_redirects` 는 빌드가 dist 에 만들어 두며 워커가 그대로 읽는다.

## 이 사이트가 구하는 값 — 넓이 반분선

동 땅을 직선으로 가르되 양쪽 넓이가 정확히 같아지는 자리를 이분법(60회)으로 찾는다.

- **남북 반분선** — 동서로 뻗어 땅을 북쪽 절반과 남쪽 절반으로 가르는 직선
- **동서 반분선** — 남북으로 뻗어 땅을 동쪽 절반과 서쪽 절반으로 가르는 직선

| 값 | 뜻 |
|---|---|
| 반분선 길이 | 각 직선이 땅 안에서 이어지는 길이(10m 단위), 땅을 드나들면 토막 수도 적음 |
| 교차점의 자리 | 두 직선이 만나는 점이 경계 상자 중앙에서 북남·동서로 벗어난 %(상자 크기 대비) |
| 치우침 | 위 두 값을 합성한 크기(%) |
| 긴 쪽과 비 | 두 직선 중 긴 쪽, 그리고 긴 쪽 / 짧은 쪽 |
| 분류 | 일곱 가지: 정중앙형·살짝 어긋난형·꽤 어긋난형·많이 어긋난형·가장자리형·동서로 긴형·남북으로 긴형 |

분류는 긴 쪽 비가 1.8배 이상이면 동서로 긴형·남북으로 긴형, 그 밖에는 치우침이 2.5%·5%·9%·14%를 넘는 순서로 나눈다.
시군구는 읍·면·동 땅을 한 덩이로 놓고 재며, 시도는 다루는 단위들의 평균을 쓴다.

## 화면 구조 — 지하철 노선도

시도가 노선 한 줄이고(번호 배지), 시군구와 동이 세로 노선선 위의 정거장이다. 값은 정거장 사이 선분의 길이로 보인다.
같은 이름의 시군구는 환승 표시와 함께 시도 이름을 붙인다.

## 커버리지

- **동까지** 서울·인천·경기·부산 — 1,232구역
- **시군구까지** 대전·대구·울산 전역 + 광주 광산구 + 지정 시·군
- 읍과 면은 안내문을 내지 않고 시군구 목록에 이름만 적는다(접수와 방문은 동일).

## 꼭 지킬 것

- `data/lastmod.json` 을 **반드시 커밋**한다. 없으면 깃 빌드에서 전 안내문이 '오늘 수정'으로 밀린다.
- 전화번호는 `callBox()` 로만 찍는다. 맨 번호가 본문에 남으면 `npm run check` 가 잡는다.
- 무작위를 쓰지 않는다. 모든 변형은 md5 시드 고정이라 같은 주소면 언제나 같은 HTML 이 나온다.
- 후기·체험담·평점·인물 사진을 싣지 않는다.
- 한글 문장은 `src/content/copy.mjs`(T), 값을 말로 옮기는 말은 `src/content/metric.mjs`(M), 마크업은 `src/lib/skin.mjs`(SK)에만 둔다. `src/lib/blocks.mjs`·`src/pages/region.mjs` 에는 한글 문장이 없다.
